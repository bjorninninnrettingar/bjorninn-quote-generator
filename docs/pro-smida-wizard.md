# PRO Smíða wizard (scoped 2026-10-28; phase 1 built 2026-10-28)

Owner brief: Smíða must work like the Studio door wizard (`openDoors` / `KPDOORS`, `uw*` Ný eining wizard): the next step is always obvious, the camera zooms between the places being worked on so nothing can go wrong, and the summary builds up underneath. Rakel must stay awake — no click-through.

## Decisions (owner + recommendation)
- **Order:** one pass through the WHOLE room, unit by unit (Sk1 → Sk2 …). A unit marked "Klár" glides the camera to the next not-ready unit; progress (7/12) is always visible (same count as the Yfirferð badge). Nothing skippable.
- **"Nothing prefilled" (owner: "I don't know, what prevents most mistakes?") → ghost + confirm:** fields start EMPTY but the drawing shows the current value as a pale ghost; the step cannot be passed until Rakel types the value or taps "Rétt" on EACH dimension (its dimension line lights up in 3D while she does). Mistakes come from skipping, not from retyping — this stops skipping without 90 retyped numbers. Same rule for every later step (count, positions, hinges): an explicit action per item, never an automatic pass.
- **Steps per unit:** 1 Mál (B × H × D, dimension lines, camera head-on like the doors' Mál) → 2 Innvols (hillur / skúffur / ofn / slá: counts) → 3 Staðsetning innvols (heights of shelves, drawer seams, oven line — dragged in the zoomed 3D or typed) → 4 Vélbúnaður (hinge positions, door type, grip side) → 5 Yfirlit ("Klár til framleiðslu").
- **Summary tray under the wizard:** chips fill as choices are made — mál, hillufjöldi, skúffur (with Sérhæð), lamir (count + mm), ofn, grip. Clicking a chip jumps back to its step.

## Build plan (data model untouched)
`b.smida`, `b.shelfPos`, `b.interior.frontsMm`, `b.ovenShelves`, `smidaFor()`, `proIssues()`, `proReady()` stay exactly as they are — /smida, Keyra skipulag and the Vinnuteikningar read the same Smíðagögn. Only the UI shell changes; the editing primitives of `renderBoxEditor` (seam drag, shelf drag, hinge markers, `KP3D.resizeFront`) are reused inside steps.
1. **Shell + Mál + summary tray + room queue** (door-wizard layout, `uwAimCamera`-style camera, `b.smidaAck = {mal:[w,h,d], …}` records what Rakel confirmed; changing the drawing drops the ack like `smidaReady` does).
2. **Innvols + Staðsetning** for door cabinets and drawer units (most units), then oven / corner / fridge / búr.
3. **Vélbúnaður** (hinges with the existing `HINGE_CLEAR` rule and height rule).
4. **Yfirlit → Klár** replaces the ⛔ list + "Klár til framleiðslu" button; Yfirferð reads the same readiness.

## Ideas (not yet agreed)
- Show what the customer chose next to what Rakel confirmed ("viðskiptavinur: 3 hillur → þú: 4").
- Check Mál against the site measurement (Mæling) when one exists; warn on > 10 mm difference.
- Enter = next, Tab = next field; Esc steps back without losing values.

## Direction change (2026-10-28, owner): Smíða IS the Ný eining wizard (`uw*`) + more steps
The right-hand panel built first (c59d2ca) was replaced. Smíða now opens `openUnitWizard()` in a Smíða mode (`uw.smida`) on the REAL cabinet (`uw.b` = the block in the room; the preview draws a copy, edits go in place + `save()`; `refreshAfterEdit()` is never called while it is open — the room scene isn't up behind the modal). Same layout, folding sections, preview, dimension lines, camera glides and Áfram / Til baka placement as Ný eining; code is the `sm*` block above `renderUnitWizard`'s callers + small `if (uw.smida)` branches inside `renderUnitWizard`, `wireUnitWizard`, `drawUwDims`, `uwAimCamera` (PRO smida also glides), `closeUnitWizard`. Entry: `openSmidaWizard(id)` (panel button, /cnc "Laga í PRO", new unit in PRO).
- **Sections (= steps):** Breidd · Hæð · Dýpt (empty field + pale dashed ghost line with the current value on the drawing; type or **Rétt**; typing a different value changes the drawing via `applyBlockDim` / `applyCarcassHeightMm`, refused values confirm nothing) · Innvols (Ný eining's own Innvols section — shelves, drawers, oven, rails, búr, door side … — plus **Innvols er rétt**) · Yfirlit (issues + Laga, Taka af merkingu, "Opna eldri Smíða-ritil").

None left = "Rýmið er klárt". Header `Smíða · Sk3 · 7/12 yfirfarnir`; chips tray under the sections (click = that section).
- **Found + fixed on the way:** two functions called `crossBounds` (6233 room rows, 12279 shelves) — the later shadowed the earlier, so `growBlock`/`growRoom` (typing a new Breidd in the editor) threw. Shelf one is now `itemCrossBounds`; a test fails on any duplicate function name in the planner script.
- **Test aid:** `window.__sm` (`open`, `uw`, `ctx`, `go`, `queue`, `chips`). Viewport ≥ 768 wide or the desktop gate shows; rAF doesn't tick in the pane (screenshots lag).

### Steps 3 + 4 (2026-10-28): Staðsetning and Vélbúnaður
Two more sections after Innvols, built from a list of ITEMS (`smItems(grp, x)`, grp `pos` / `hw`); a section only shows when the cabinet has items.
- **mm item** = empty field + **Rétt** (the current value is a pale dashed line across the cabinet in the preview, blue while its field has focus, dark with a tick once confirmed; doors open in these sections). **Choice item** = buttons, the current one only outlined until she picks one. Typing a different value runs the old editor's own mutation (same setters), so `smidaFor()` comes out as before.
- **Staðsetning (`pos`)**: Sérhæð per drawer seam, Hæð undir ofni, every shelf (mm + Föst/Laus toggle — the ack value is `mm+F|L`), Fataslár, búr / free-form innskúffur (mm).
- **Vélbúnaður (`hw`)**: Skipting fronta (+ hæð of each front), hinge side (not when two leaves), per door Gerð (Á lömum / Lyftihurð / Rennihurð, kerfi for pocket) and every hinge's mm frá botni hurðar (✕ to remove below the minimum, ＋ Löm; the 30 mm rule toasts, shelf-hole clashes show in Yfirlit with "Laga" = `proAutoHinges`), Grip per front (Ekkert / Alla leið / Hluti → brún / átt / frá botni / lengd).
- **Ack:** `b.smidaAck.pos` / `.hw` = `{ itemId: value-string }`, valid only while equal to the current value (`smItemAckOk`). `smInnSig` uses the normalised shelf/rail COUNT (`KP3D.shelvesOf/railsOf`) so typing positions doesn't drop the Innvols ack.
- **`refreshAfterEdit()` is a no-op while `uw.smida`** (legacy helpers like `proSetGrip`, `proAutoHinges`, `proFixDrawers` call it; the preview is the one 3D scene). The room is rebuilt on close.
- **Yfirlit:** the "old editor" link remains ONLY for bath basin units (holes in the top, `bathSinkUnit`). Not covered by the wizard yet: raðborun toggle, shelf lock / "Dreifa jafnt", bath top holes, closet LED — use the old editor via the Yfirferð ⛔ / the unit panel if needed.

## Round 2 (2026-10-30)
Owner feedback after testing round 1 on T-32 (8 points). Built in four small steps; each ends with what to click in T-32.

**A — choices, undo, colours, current values (built):** the chosen option of every Smíða choice (Föst/Laus/Læst, Gerð, Skipting fronta, Raðborun Af/Á, Grip, Hurðir/Skúffur) is solid blue, the rest neutral (the dashed "suggest" is gone); each choice row now has its own Rétt. Raðborun was never on by data — Af just wasn't shown as chosen. **Rétt ✓ is a toggle**: pressing a confirmed item again removes its ack (`smUnack`; keys under `smidaAck.mal/inn/pos/hw` only, and a cabinet that was Klár stops being Klár). Fields always show the CURRENT value (selected on focus); Enter confirms what the field shows; Rétt on fjöldi gata / bil milli gata confirms exactly the shown number. Yfirlit rows (Vantar enn, Laga) use the dark panel tokens.
*Click in T-32:* open a cabinet in Smíða → Staðsetning: Raðborun shows Af in blue; press Rétt on Hilla 1 (✓), press ✓ again (back to Rétt); change "bil milli gata" and press Enter; Yfirlit: rows are dark with readable text.

**B — drag through (built):** in PRO and in Smíða a shelf / fataslá drags through its neighbours (only the cabinet's own top/bottom limits it; `smMoveThrough`, the customer's Studio wizard keeps the old neighbour limits). The list is written sorted on every move, so `smidaFor`, `cnc-sides.js` and the drawings read the same shape. A real clash left at the drop (two items closer than 40 mm) is the first line in Yfirlit "Vantar enn" and holds back Áfram/Klár (`proClashes`; deliberately NOT in `proIssues`/`proReady`, so cabinets already Klár stay Klár). Typing a position past a neighbour now confirms the item where it ended up. Also fixed: dragging a shelf used to drop its "bil milli gata".
*Click in T-32:* Smíða → Innvols/Staðsetning, drag a hilla (or Fataslá) up through the next one — it passes and stays where dropped; drop it within 40 mm of another and Yfirlit says "… of nálægt hvort öðru"; drop clear and the line is gone.

**C — one shelf per screen (built):** Staðsetning now shows ONE screen at a time (`smPosScreens`): each shelf is "Hilla 2 af 4" — the camera lifts to its height (`uw.smFocusAbs` → `uwAimCamera`), a blue band + line marks it on the drawing (a typed value moves the line live), the field holds its CURRENT mm, Föst / Laus / Læst are blue when chosen, and "Gataröð" (fjöldi gata, bil milli gata, both pre-filled) appears only for a Laus shelf. ONE Rétt (or Enter in any field) applies what the fields show and confirms exactly that — the acks stay per item (`pos.shK / shpK / shgK`, same shapes); pressing ✓ again takes it back. Everything that isn't a shelf (Sérhæð, ofn, Raðborun, slár, innskúffur, bath holes, "Dreifa jafnt") keeps its rows on an "Aðrir hlutir" screen. Áfram/Til baka step through the screens; Yfirlit rows jump to the right screen; moving a shelf past another confirms it where it ended up and continues at the screen that is still open.
*Click in T-32:* Smíða → Staðsetning: first screen is "Hilla 1 af N", camera on that shelf; type a new mm (line follows), Enter → next shelf; choose Föst → the hole rows vanish; choose Laus → they are back with numbers in them; press Rétt without touching them — the numbers stay; ✓ takes it back; Til baka goes to the previous shelf.

**D — Lamir, one hinge per screen (built):** "Vélbúnaður" is split into **Lamir** (right after Staðsetning) and **Grip** (the old `hw` section). Lamir opens on "Fyrir lamirnar" (Skipting fronta, Hlið, Gerð per door) and then one screen per hinge, "Löm 2 af 4 · Hurð 1": the camera goes close to that hinge from the hinge side, only that hinge is drawn (no dotted lines for the rest), the light-blue clearance bands show only within ~230 mm of it, the field holds its CURRENT mm, and a hinge on a shelf hole / fixed shelf / runner is **red with the reason** and **Rétt is dead**; "Færa í N mm" moves it to the nearest clear spot (the `proAutoHinges` rule — 30 mm from holes/ends, 60 mm between hinges — for this one hinge) but does not confirm it. Áfram pages through hinges to look at them (a red one holds the page); **Allar lamir rétt** shows only on a door's last hinge, when all its hinges were shown and none is red. Dragging a hinge on the preview still works (the drop moves it; Rétt confirms). Acks are still `smidaAck.hw["hgI_J"]` (+ `split`, `dtI`, `side`), so cabinets already Klár stay Klár; `smidaFor`/`smidaHash`/`proReady`/`proIssues` untouched.
*Click in T-32:* open a cabinet with doors → Lamir: confirm "Fyrir lamirnar", then "Löm 1 af N": camera is on the hinge, only it is drawn; type a number that lands on a shelf hole (e.g. the shelf's hole row) + Enter → red with the reason, Rétt greyed; press "Færa í … mm" → no longer red → Rétt → next hinge; on the last hinge press "Allar lamir rétt" → Yfirlit.
