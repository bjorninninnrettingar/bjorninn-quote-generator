# PRO Smíða wizard (scoped 2026-10-28; phase 1 built 2026-10-28)

Owner brief: Smíða must work like the Studio door wizard (`openDoors` / `KPDOORS`, `uw*` Ný eining wizard): the next step is always obvious, the camera zooms between the places being worked on so nothing can go wrong, and the summary builds up underneath. Rakel must stay awake — no click-through.

## Decisions (owner + recommendation)
- **Order:** one pass through the WHOLE room, unit by unit (Sk1 → Sk2 …). A unit marked "Klár" glides the camera to the next not-ready unit; progress (7/12) is always visible (same count as the Yfirferð badge). Nothing skippable.
- **"Nothing prefilled" (owner: "I don't know, what prevents most mistakes?") → ghost + confirm:** fields start EMPTY but the drawing shows the current value as a pale ghost; the step cannot be passed until Rakel types the value or taps "Rétt" on EACH dimension (its dimension line lights up in 3D while she does). Mistakes come from skipping, not from retyping — this stops skipping without 90 retyped numbers. Same rule for every later step (count, positions, hinges): an explicit action per item, never an automatic pass.
- **Steps per unit:** 1 Mál (B × H × D, dimension lines, camera head-on like the doors' Mál) → 2 Innvols (hillur / skúffur / ofn / slá: counts) → 3 Staðsetning innvols (heights of shelves, drawer seams, oven line — dragged in the zoomed 3D or typed) → 4 Vélbúnaður (hinge positions, door type, grip side) → 5 Yfirlit ("Klár til framleiðslu").
- **Summary tray under the wizard:** chips fill as choices are made — mál, hillufjöldi, skúffur (with Sérhæð), lamir (count + mm), ofn, grip. Clicking a chip jumps back to its step.

## Build plan (data model untouched)
`b.smida`, `b.shelfPos`, `b.interior.frontsMm`, `b.ovenShelves`, `smidaFor()`, `proIssues()`, `proReady()` stay exactly as they are — /smida, Keyra skipulag and the Vinnuteikningar read the same Smíðagögn. Only the UI shell changes; the editing primitives of `renderBoxEditor` (seam drag, shelf drag, hinge markers, `KP3D.resizeFront`) are reused inside steps.
1. **Shell + Mál + summary tray + room queue** (door-wizard layout, `uwAimCamera`-style camera, `b.smidaAck = {mal:[w,h,d], …}` records what Rakel confirmed; changing the drawing drops the ack like `smidaReady` does).
2. **Innvols + Staðsetning** for door cabinets and drawer units (most units), then oven / corner / fridge / búr.
3. **Vélbúnaður** (hinges with the existing `HINGE_CLEAR` rule and height rule).
4. **Yfirlit → Klár** replaces the ⛔ list + "Klár til framleiðslu" button; Yfirferð reads the same readiness.

### Steps 3 + 4 (2026-10-28): Staðsetning and Vélbúnaður
Two more sections after Innvols, built from a list of ITEMS (`smItems(grp, x)`, grp `pos` / `hw`); a section only shows when the cabinet has items.
- **mm item** = empty field + **Rétt** (the current value is a pale dashed line across the cabinet in the preview, blue while its field has focus, dark with a tick once confirmed; doors open in these sections). **Choice item** = buttons, the current one only outlined until she picks one. Typing a different value runs the old editor's own mutation (same setters), so `smidaFor()` comes out as before.
- **Staðsetning (`pos`)**: Sérhæð per drawer seam, Hæð undir ofni, every shelf (mm + Föst/Laus toggle — the ack value is `mm+F|L`), Fataslár, búr / free-form innskúffur (mm).
- **Vélbúnaður (`hw`)**: Skipting fronta (+ hæð of each front), hinge side (not when two leaves), per door Gerð (Á lömum / Lyftihurð / Rennihurð, kerfi for pocket) and every hinge's mm frá botni hurðar (✕ to remove below the minimum, ＋ Löm; the 30 mm rule toasts, shelf-hole clashes show in Yfirlit with "Laga" = `proAutoHinges`), Grip per front (Ekkert / Alla leið / Hluti → brún / átt / frá botni / lengd).
- **Ack:** `b.smidaAck.pos` / `.hw` = `{ itemId: value-string }`, valid only while equal to the current value (`smItemAckOk`). `smInnSig` uses the normalised shelf/rail COUNT (`KP3D.shelvesOf/railsOf`) so typing positions doesn't drop the Innvols ack.
- **`refreshAfterEdit()` is a no-op while `uw.smida`** (legacy helpers like `proSetGrip`, `proAutoHinges`, `proFixDrawers` call it; the preview is the one 3D scene). The room is rebuilt on close.
- **Yfirlit:** the "old editor" link remains ONLY for bath basin units (holes in the top, `bathSinkUnit`). Not covered by the wizard yet: raðborun toggle, shelf lock / "Dreifa jafnt", bath top holes, closet LED — use the old editor via the Yfirferð ⛔ / the unit panel if needed.

5. **Grip (answer to the owner):** the Smíða "Grip" zones are ONLY the milled grip (Fræst grip): per front **Ekkert / Alla leið** (horizontal rout along the whole front edge, the front shrinks 35 mm, brún efst/neðst) or **Hluti** (a milled section: átt, mm frá botni fronts, lengd). They go to Eyðublað "Grip svæði (JSON)" and /cnc flags them "fræst í höndunum". **Jey, Hexxa and Spónagrip are NOT zones** — they are the project's handle (Efni → Höldur), reach the Eyðublað as "Grip?" (Jey −27, Hexxa −1) and drive the front cut size; nothing to position per front. The wizard therefore shows, when the project handle is Jey/Hexxa/Spónagrip, one line "gripið kemur af höldunni" and no zone choices (zones that already exist stay editable so they can be removed); other handles keep the Fræst grip choices.
6. **Klár never dead:** Áfram/Klár are never disabled — an incomplete step answers with a toast and focuses the first missing item; **Yfirlit** shows "Vantar enn (N)" with every unconfirmed dimension / Innvols / item and every `proIssues` entry (Laga button), each clickable. (Likely cause in real PRO: a real unit has issues — default hinges on shelf holes, drawer sums — and many items, so `can` was false with no explanation.)
7. **Free orbit** in Smíða mode (azimuth/polar limits removed, no auto-rotate); customers' Ný eining keeps its limits.
