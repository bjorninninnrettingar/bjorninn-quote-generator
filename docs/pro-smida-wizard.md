# PRO Smíða wizard (scoped 2026-10-28; phase 1 built 2026-10-28)

Owner brief: Smíða must work like the Studio door wizard (`openDoors` / `KPDOORS`, `uw*` Ný eining wizard): the next step is always obvious, the camera zooms between the places being worked on so nothing can go wrong, and the summary builds up underneath. Rakel must stay awake — no click-through.

## Decisions (owner + recommendation)
- **Order:** one pass through the WHOLE room, unit by unit (Sk1 → Sk2 …). A unit marked "Klár" glides the camera to the next not-ready unit; progress (7/12) is always visible (same count as the Yfirferð badge). Nothing skippable.
- **"Nothing prefilled" (owner: "I don't know, what prevents most mistakes?") → ghost + confirm:** fields start EMPTY but the drawing shows the current value as a pale ghost; the step cannot be passed until Rakel types the value or taps "Rétt" on EACH dimension (its dimension line lights up in 3D while she does). Mistakes come from skipping, not from retyping — this stops skipping without 90 retyped numbers. Same rule for every later step (count, positions, hinges): an explicit action per item, never an automatic pass.
- **Steps per unit:** 1 Mál (B × H × D, dimension lines, camera head-on like the doors' Mál) → 2 Innvols (hillur / skúffur / ofn / slá: counts) → 3 Staðsetning innvols (heights of shelves, drawer seams, oven line — dragged in the zoomed 3D or typed) → 4 Vélbúnaður (hinge positions, door type, grip side) → 5 Yfirlit ("Klár til framleiðslu").
- **Summary tray under the wizard:** chips fill as choices are made — mál, hillufjöldi, skúffur (with Sérhæð), lamir (count + mm), ofn, grip. Clicking a chip jumps back to its step.

## Build plan (data model untouched)
`b.smida`, `b.shelfPos`, `b.interior.frontsMm`, `b.ovenShelves`, `smidaFor()`, `proIssues()`, `proReady()` stay exactly as they are — /smida, Keyra skipulag and the Vinnuteikningar read the same Smíðagögn. Only the UI shell changes; the editing primitives of `renderBoxEditor` (seam drag, shelf drag, hinge markers, `KP3D.resizeFront`) are reused inside steps.
1. **Shell + Mál + summary tray + room queue** (door-wizard layout, `uwAimCamera`-style camera, `b.smidaAck = {mal:[w,h,d], …}` records what Rakel confirmed; changing the drawing drops the ack like `smidaReady` does).
2. **Innvols + Staðsetning** for door cabinets and drawer units (most units), then oven / corner / fridge / búr.
3. **Vélbúnaður** (hinges with the existing `HINGE_CLEAR` rule and height rule).
4. **Yfirlit → Klár** replaces the ⛔ list + "Klár til framleiðslu" button; Yfirferð reads the same readiness.

## Ideas (not yet agreed)
- Show what the customer chose next to what Rakel confirmed ("viðskiptavinur: 3 hillur → þú: 4").
- Check Mál against the site measurement (Mæling) when one exists; warn on > 10 mm difference.
- Enter = next, Tab = next field; Esc steps back without losing values.

## Phase 1 — built (2026-10-28)
Code: `kitchen-planner.html`, block "Smíða wizard" (`pw*`, `openSmidaWizard`) right above `renderBoxEditor`; CSS `#proWiz`; test `tests/kp-smida-wizard.test.js`.
- **Shell:** a non-modal dark panel on the right over the LIVE room 3D (not a separate preview scene like `uw`/`dw`, because the queue glides the room camera between units). Header `Sk3 · Grunnskápur` + progress `ok/total` (counts `proSkList()` — every ordered unit in every room; same "yfirfarinn" as the Yfirferð Smíða item), step rail `1 Mál · 2 Innvols · 3 Yfirlit` (phase 2–3 split Innvols), `Til baka` / `Áfram` fixed at the bottom (never move; step 3 says `Klár`), one hint line, summary tray of chips (click = back to its step; pale `—` until reached, Mál fills on confirm).
- **Entry points:** panel button "Smíða — …", `proOpenSk` (/cnc "Laga í PRO"), new unit in PRO now open the wizard. Yfirferð's ⛔ "Laga" and the first-unit auto-open still open the OLD editor (`openBoxEditor`), and step 2 has "Opna Smíða-ritilinn" — old editor stays until phases 2–4 replace its parts. When it closes the wizard refreshes (`pwBack`, follows its own "Yfirfarinn → Sk8" jump). Works in PRO and in `?scene=` test scenes (`!PRO && !SCENE` returns).
- **Mál step:** Breidd / Hæð (carcass, same meaning as everywhere — `proBodyMm`, set with `applyCarcassHeightMm`) / Dýpt. Inputs start EMPTY; the 3D shows the current value as a pale dashed ghost line + pill; focusing a row lights its line blue and glides the camera (Breidd/Hæð head-on, Dýpt from the side); typing the SAME value or tapping **Rétt** confirms; typing a DIFFERENT value changes the drawing (`applyBlockDim`, validated, locked units refuse) and confirms that. Enter moves to the next unconfirmed row. `Áfram` stays disabled until all three are confirmed.
- **Ack:** `b.smidaAck = { mal:{ w, h, d }, at }` — the mm Rakel confirmed. `pwAckOk` = stored mm === current mm, so ANY later change of that dimension (anywhere) drops it with no extra bookkeeping (the `smidaReady`/`smidaHash` idea, per dimension). It is NOT in `smidaFor`/`smidaHash`/`proReady`/`proIssues` (test guards this); copying a cabinet deletes it. A unit whose Mál is already confirmed opens at step 2.
- **Queue:** `Klár` (step 3, needs Mál confirmed + no `proIssues`; shows the issues with the same "Laga" actions as the old editor) → `proSetReady` → `proNextUnready` (wraps, crosses rooms via `openRoom`) → `pwGo` glides the camera. None left = "Rýmið er klárt" with `Loka`. Nothing skippable (no skip button; ✕ / Esc leaves).
- **Camera:** `pwAim` copies `uwAimCamera`'s distance maths from the unit's world box (`pwGeo` = `surfaceGeoms` + `blockStartsMm`), 700 ms ease, shifted so the unit sits in the free part left of the panel (checked numerically: every unit of the bath scene projects inside the free area).
- **Test aid:** `window.__pw` (`open(id)`, `state()`, `ctx()`, `go(uid)`, `queue()`, `draw()`, `aim(animate)`). In the Browser pane rAF doesn't tick, so call `__pw.draw()` / `__pw.aim(false)` by hand; viewport must be ≥ 768 wide (`resize_window` 1440×900) or the desktop gate shows.
- **Not done / next:** phase 2 Innvols + Staðsetning (reuse seam/shelf drag), phase 3 Vélbúnaður, phase 4 Yfirlit replaces the ⛔ list; the "ideas" above (customer's choice next to hers, Mæling check). Queue order interleaves `Sk`/`UH` of equal number (`proSkList` sort) — Sk1, UH1, Sk2, UH2 … — acceptable, revisit if she finds it odd. Hung bath units (`state.hungUnits`) aren't offset in `pwGeo` yet.
