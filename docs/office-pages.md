- **/ferli** (surgical pass, all the existing stage logic kept): kanban → ONE flat, compact list (not grouped — kept short on purpose): search box + filter chips with counts (Allt / Þarf athygli / one per stage); each row has a stage-coloured pill + left edge (For-skipulag yellow, Í skipulagningu red, Yfirfara blue, Pöntunarlisti purple), delivery text (red when late), "Pöntun opin" tag; untouched ≥5 days sort first. **Drag into Pöntunarlisti removed** (too easy to trigger by accident; the project page's "Merkja Klárt" runs the same KLÁRT gate + notification). Emoji removed from static labels/toggles (Airtable values/field names keep theirs, e.g. stage names).

## Modular layout (2026-10-29)
[office-grid.js](../office-grid.js) — every block is a widget on a 12-column grid (row unit 64 px): "Breyta útliti" (CRM: Meira menu; Framleiðsla project page: link by the stage line) shows a grip (drag to reorder), width presets (¼ ⅓ ½ ⅔ Allt), a corner handle (drag = width in columns + height in rows), × to hide, and "Bæta við…" for hidden ones; "Endurstilla" restores the page defaults; Esc/Klára leaves. Saved per person + page in localStorage (`bjorninn:grid:<key>:<name>`) — device-local, not synced. Below 900 px it is one column and editing is off. `force: true` widgets hide themselves when empty (shown anyway while editing). CRM widgets: kpi, pipeline, nextSteps, inquiries, toReview, pipelineReport (hidden by default; "Tölfræði söluferlis" in Meira toggles it). Framleiðsla project widgets: g-stada/athugid/undirb/teikn/saga/opna/nanar. Pages now use the full screen width (CRM and Framleiðsla `max-width:none`). Not yet on the grid: /ferli list, /starfsmenn (single lists — say if wanted).
