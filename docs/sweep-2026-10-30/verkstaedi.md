# Sweep 2026-10-30 — floor-side pages (verkstæði)

Pages: `/app`, `/verk-i-gangi`, `/verk`, `/velja` (via `/v/<pieceId>`), `/labels`, `/fraesing`, `/saga` (grain.html FLOOR_MODE), `/velar`, `/verkstaedi`, `/tv`.
Tested read-only on https://bjorninn.vercel.app (T-31 `recHRMM3MfOXHGAaE`, one real piece for `/v/`), at 375x812, 768x1024 and (/tv) 1920x1080. Nothing written to Airtable, no buttons pressed. No page files edited.

## Summary

1. No console errors, failed calls or dead links on any page in normal use. The only 4xx in the console were my own bad-id probes. `/app` PWA is sound (manifest + icons 200, SW active).
2. Biggest real bug: **`/labels` is unusable on a phone**. The 6-column row grid has no `@media`, the page scrolls sideways (618px at 375px) and the green/blue print button sits at x≈555, off screen. `/app` → "Sög" sends phones there.
3. **`/saga` is the odd one out visually**: light theme, system font, truncated project name, while every other floor page is dark Kumbh Sans.
4. **`/tv` is too small for a TV**: 4 projects fill the top third of a 1080p screen, project names are 19px, labels 12px. Month names depend on the TV browser having an `is-IS` locale.
5. **No on-screen help and no chatbot on any floor page.** `leidbeiningar` is linked from none of them. The widget can be dropped in, but `api/chat.js` only answers when `context.app === "studio"` (line 120), so a floor mode is needed first.

## Help line and chatbot

- **On-screen help:** none of the ten pages has a help line or Hjálp entry. Each has a one-line subtitle ("Veldu verkefni…", "ýttu á stykki þegar það er fullfræst."). `leidbeiningar.html` is linked from none (grep = 0 in all ten), even though docs/app-floor.md says cutlist and labels are used together with it. Suggested: one "?" link in each header → `/leidbeiningar#<page>`.
- **Chatbot:** not present on any floor page. It is embedded on the public Wix site as a Custom Code `<script src="https://bjorninn.vercel.app/chat-widget.js">` (Shadow DOM, hard-gated to `location.pathname === "/"`, [chat-widget.js:65](chat-widget.js:65)) and, in "studio" mode, injected by [kitchen-planner.html:21663-21667](kitchen-planner.html:21663) after setting `window.BJORNINN_CHAT = {mode:"studio",lang,getContext}`.
- **How to drop it into the floor pages (one tag + a context string):**
  1. In chat-widget.js read `var s=document.currentScript; CFG = window.BJORNINN_CHAT || {mode:s.dataset.mode, context:s.dataset.context}` and add `mode:"floor"` next to `STUDIO` (own greeting, no contact-page link, `API_BASE=""`, launcher bottom-left so it does not cover print/save buttons).
  2. In api/chat.js ([line 120](api/chat.js:120) `ctx.app !== "studio"` → also accept `"floor"`) add `buildFloorPrompt()` built from docs/app-floor.md + leidbeiningar.html and render `ctx.page` ("labels", "fraesing", "saga", "velja", "app") into the prompt.
  3. Each page then needs only: `<script src="/chat-widget.js" data-mode="floor" data-context="labels" defer></script>`.
  Exclude `/tv` (no interaction) and be careful on `/velja` (full-width bottom button). Size: L (~1-2 h, mostly the prompt/guide), the per-page tag is S.
