# Studio (customer planner) — second audit, 2026-10-30

Scope: everything in `/skipuleggja` beyond the Eldhús flow already covered in [customer.md](customer.md): editor at 1024×768 and 1280×800, the other rooms, Rýmin þín, EN mode, draft restore, Senda inn + contact (up to, never including, submit), static review of `api/kp-submit.js`, performance.
Method: local `python3 -m http.server 4398`, Browser pane, JS-driven clicks. `/api` 404s are expected. For the contact step `window.fetch` was stubbed to log+reject any `/api/kp-*` call before the empty/bad-form clicks (0 calls were made; the form validation stopped them). Nothing submitted, no Airtable writes, no file in the repo changed except this report. The draft lives only in the pane's localStorage.

## Summary
1. No customer-blocking bug. Fataskápur, Baðherbergi, Þvottahús, Innihurðir, Rýmin þín, Spurningar and the contact step all work at 1024×768, no page scroll on any of them (`scrollHeight == innerHeight` everywhere), no console errors, Ný eining/undo/redo/X-Ray/Málband work.
2. Fix A claims verified: item 6 (title at 1024: title spans x 18–198, stepper starts 266 — no clipping) and item 5 (suggestion card shows alone; the "Tillagan er bara byrjun" hint is deferred to after the card, kitchen-planner.html:4654). Gate now reacts to resize (tested 700 ↔ 1280).
3. **One real layout bug introduced by the stepper being absolutely centred: in the editor the "Rýmin þín" header button is covered by the "3 Skipulag" pill at 1024 (81 px overlap, clicks hit the pill) and touches it at 1280 (14 px).** "Klárt — aftur í rýmin" does the same job, so minor, but the button is invisible to the customer.
4. EN mode is switched off in the product (`ENGLISH_ON`); forced on in-browser it is clean: 0 untranslated keys except 33 Egger product names (by design) and four room names in the contact summary captions.
5. Not tested: real drag-to-move/resize in 3D (synthetic pointer drags unreliable in the pane — only width via the side panel and Ný eining placement), Þvottahús/Bað 3D visuals in depth, real-hardware FPS (rAF throttled), mid-flow reload in shape/materials steps, the actual submit and thank-you screen.
