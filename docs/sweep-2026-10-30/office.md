# Office-side audit — 2026-10-30 (report only, nothing edited, nothing written to live Airtable)

Scope: ferli, yfirferd (stub), skrifstofa, crm, pontun, framleidsla, dagatal, para-taeki, starfsmenn, bakendi, skipulag (stub), bjorninn + the api/*.js they call.
Method: static read of every write path + pages loaded in the Browser pane through a **local proxy (port 4399) that injects a fetch mock** — every `/api/*` call is answered by the mock and recorded, nothing leaves the machine. No office key was used or sought. Mock modes: ok / err (403/500) / empty.

## Top summary

1. **/api/skrifstofa-login has no rate limit and accepts 3–4 digit numeric PINs, and a correct PIN returns the master `VERK_KEY`** (api/skrifstofa-login.js:70-74, 96-103). ~10 000 guesses = full office write access (order sending, status moves). The `return=` param after login is also an unvalidated `location.href` (skrifstofa.html ~510) → `javascript:`/off-site redirect.
2. **/ferli writes on page view, with no click:** opening a project whose units are all reviewed PATCHes `Staða í skipulagi → Yfirfara` (ferli.html:761-767) and may PATCH `1. Dagssetningar ákveðnar` (ferli.html:1098-1105). Both observed in the mock. It is documented/owner-approved, but it fires `🔔 Virkni-logg — Stöður` (bell line) from merely looking.
3. **Failed writes look like success** in the three automation triggers of /ferli (Keyra skipulag, Búa til pöntunarlista, Yfirfarin — næsta) and in /pontun (Sent kl., status dropdown, Efni lent + floor chat): `apiPatch` resolves the JSON body even on 403, nobody checks `r.error`. With an expired/missing key Rakel sees "Keyri…" for 2.5 min, and /pontun can post a real "Allt efni komið í hús" chat to the floor although the tick was refused.
4. **The /ferli board hides failure and probably a limit:** an API error renders as four empty columns ("Ekkert hér ×4") instead of the retry note, and the project query is `pageSize=100` with no offset and *includes delivered projects* (filtered client-side) — once more than 100 projects are "unnið", live ones silently drop off the board.
5. **None of the 10 office pages load `bjorninn-tokens.css`** (batches A–E skipped them): accent `#0f6cbd` instead of brand `#3d61c1`, system font stack instead of Kumbh Sans, stage colours differ between /ferli and /skrifstofa, emoji in pontun/para-taeki/dagatal/bjorninn, and the shared sidebar has **no mobile rule** (at 375 px it takes 224 px and the page is unusable).

## What is still missing before `LOCKS_ON` can flip (from docs/skipulagsleidin-redesign.md + code)

1. **Never tested with locks on on a live project** (docs: "kveikja lásana og prófa á lifandi verki (T-32)").
2. **Sync after PRO edits** is deferred (decision 4) — with locks on, a project whose Line Items change after "Keyra skipulag" can't get back through step 1 (`⚠️ Breytt eftir stofnun` only warns).
3. **#11** — step-4 gate string equality vs regex; confirm real `Staða` choice names, or step 4 may never open.
4. **#4/#9** — error handling: with locks on, an unreadable signal is "not done" (good), but write failures that look like success will leave a step stuck with no explanation.
5. Order step: **cannot add a brand-new order line** (docs "NOT done"), cost % assumes `Áætlaður kostnaður` is ex-VAT and `💰 Tilboðsupphæð` incl. VAT (docs: unconfirmed) — verify before the owner trusts "Innkaup af tilboði %".
6. Step 3b–3d tools still open in new tabs ("Opna í nýjum flipa ↗") in my render; redesign C promised embedding (code has lazy iframes on expand — check on a real project).
7. Whether the send automation regenerates the PDF (#7) decides if the stale-PDF guard is enough.
