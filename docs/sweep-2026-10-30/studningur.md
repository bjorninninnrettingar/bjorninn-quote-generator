## HELP — chatbot widget

- **Present on these five pages? No.** `grep chat-widget` hits only `kitchen-planner.html` (Studio, see below), `api/chat.js`, docs.
- **How it is embedded on the public site (project_chatbot):** `chat-widget.js` is a self-contained Shadow-DOM script; Wix Custom Code injects one `<script src="https://bjorninn.vercel.app/chat-widget.js">` (page scope set in Wix, "All pages"). Off Wix it uses absolute API base `https://bjorninn.vercel.app` (`chat-widget.js:28-31`); `api/_cors.js` allows the Wix domain. It has a FAQ tab that iframes `faq.html` (height via the `faq:height` postMessage, which is why faq.html has the compact mode). Answers come from `api/chat.js` → Claude Haiku, grounded on `FAQ_CORPUS` in `api/_chatbot-faq-prompt.js`; finished chats are logged to Airtable `Vefspjall 💬` with the page name in `Síða`; per-IP limiter 20/min, 200/day.
- **Already a second mode:** Studio sets `window.BJORNINN_CHAT = {mode:"studio", lang, getContext}` *before* loading the same file (`kitchen-planner.html:21664-21667`); `api/chat.js` then takes `context:{app:"studio", where, step, room…}` (allow-listed keys, 200 chars each, `STUDIO_CONTEXT_KEYS` line 38) and answers from a Studio guide with its own link whitelist.
- **To make it one script tag + per-page context string for every tool:** (1) in `chat-widget.js` read config from `document.currentScript.dataset` too (`data-app="klukka" data-context="…"`) as a fallback to `window.BJORNINN_CHAT`; (2) generalise `mode` from `studio|default` to an `app` key and have `api/chat.js` pick a system prompt per `app` (a `PROMPTS = {faq, studio, klukka, sop, floor, …}` map next to `buildStudioPrompt`) with its own link-key whitelist (like `STUDIO_LINK_MAP`); (3) for internal tools gate the endpoint (floor key / skrifstofa session) so the staff prompts, which may mention PIN flow and HR rules, are not public, and log `Síða`=app. (4) Hide launcher on kiosk pages (`/klukka`): it must not cover the PIN pad. Each page then needs exactly `<script src="/chat-widget.js" data-app="…"></script>`.
