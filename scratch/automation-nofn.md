# Ný nöfn á automations (2026-10-27)

Tvísmella á nafnið í Airtable → líma nýja nafnið → Enter. Bara nafnið breytist.
Búðu líka til **Sections** (möppur) með fyrirsögnunum hér að neðan og dragðu automationin inn.

## 1 · Sala
| Núna | Nýtt nafn |
|---|---|
| Færir verk -> "tækifæri unnið 🏆" | Sala · Unnið → For-skipulag + chat |
| Skráir tíma þegar verk var samþykkt | Sala · Unnið → frysta tilboð |
| Skráir tíma þegar tilboð var sent | Sala · Tilboð sent → dagsetning |
| Eftirfylgni 1.0 📧 G.CHAT | Sala · Eftirfylgni 3 dagar → chat |
| Eftirfylgni 2.0 📧 G.CHAT — 15 dagar | Sala · Eftirfylgni 15 dagar → chat |
| Verk ósnert í 30 daga -> Tæk. tapað🥀 | Sala · Ósnert 30 dagar → Tapað |
| Næsta söluskref - G.CHAT | Sala · Næsta söluskref → chat |
| Smásala A-Ö | Sala · Smásala → beint í Lokið |
| Skráir ár og mánuð (staðfesting + afhending) | Sala · Staðfest/afhent → ár og mánuður |
